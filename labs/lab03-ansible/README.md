# Лабораторная работа №2 — Ansible + Caddy
Лабораторная работа по дисциплине «Администрирование компьютерных сетей».



## Цель работы
Установить и настроить Ansible и веб-сервер Caddy на удалённой виртуальной машине.


## Выполнено
- установлен и настроен Ansible;
- создан inventory для целевого хоста;
- изучены ad-hoc команды Ansible;
- Caddy установлен с использованием Ansible role;
- создан шаблон конфигурации Caddyfile через Jinja2;
- подключён домен DuckDNS;
- настроен HTTPS;
- настроено логирование Caddy;
- создан playbook для создания, проверки, изменения и удаления тестового файла.


## Структура
- `ansible.cfg` — конфигурация Ansible;
- `inventory/hosts` — список целевых хостов;
- `caddy\_deploy.yml` — основной playbook установки и настройки Caddy;
- `roles/caddy\_deploy/` — роль Ansible для установки и настройки Caddy;
- `file\_tasks.yml` — playbook для работы с тестовым файлом;
- `lab2(3)\_Ansible\_Caddy\_report.pdf` — отчёт по лабораторной работе.
